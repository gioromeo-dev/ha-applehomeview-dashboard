# Home View Studio

Visual editor for the **Home View** iPad dashboard. / Editor visuale per la dashboard **Home View** per iPad.

1. Install from HACS / Installa da HACS: button-card, Bubble Card, WallPanel, Swipe Navigation, Kiosk Mode, card-mod.
2. Open the add-on from the sidebar / Apri l'add-on dalla barra laterale.
3. Build the Home in **Items**, style it in **Appearance** and **Behavior**, pick sources and language in **General**.
   / Componi la Home in **Elementi**, personalizzala in **Aspetto** e **Comportamento**, scegli sorgenti e lingua in **Generale**.
4. Press **Apply to dashboard** / **Applica alla dashboard**, then open `/home-view/home` on the iPad.

Full guide, sources and licenses / Guida completa, fonti e licenze: https://github.com/gioromeo-dev/ha-applehomeview-dashboard
